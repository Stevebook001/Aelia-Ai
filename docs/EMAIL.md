# AELIA Email

Use the `@aeliaai.org` domain for official product communication.

Recommended mailboxes/aliases:
- hello@aeliaai.org
- support@aeliaai.org
- security@aeliaai.org
- privacy@aeliaai.org
- developers@aeliaai.org
- billing@aeliaai.org
- partnerships@aeliaai.org
- no-reply@aeliaai.org

Provisioning these addresses requires an email provider or mail server. The code only reserves the addresses and SMTP environment variables; it cannot create the mailboxes by itself.

Before launch also configure SPF, DKIM and DMARC for aeliaai.org.
