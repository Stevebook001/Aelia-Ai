How approval works

Submitting this form does not grant API access. AELIA uses multiple gates to protect both platforms.

  1. 1
    Application screening
    We review the organization, use case, requested scopes and website.
  2. 2
    Domain ownership proof
    Publish a unique DNS TXT record under your own domain.
  3. 3
    Contact email verification
    The authorized contact must confirm the email address.
  4. 4
    Manual security review
    An AELIA administrator reviews identity, purpose and least-privilege access.
  5. 5
    Credential issuance
    Only after approval is a scoped, expiring credential created.

Important: Never publish the issued API key in source code, a public repository, client-side JavaScript or a screenshot.
